# 插件面板 ⇄ 控制台 功能对照

用户要求：「两边插件面板进度要同步，不然万一漏了」。

做法：**把"哪边有什么"固化成一张表**，并写一个脚本自动核对 ——
新增功能时先加一行，脚本会告诉你另一边还缺什么。

## 明确的"故意不同"

这几项**不该**同步，写下来避免以后被当成漏项：

- **模型测速**：控制台是"看数据"的地方，测速是"发一次真请求试试"，
  属于对话侧操作。放控制台会让人以为它只影响控制台。
- **隐藏未列出 / 只列免费**：这两个筛选作用于插件自己的模型选择器列表，
  控制台没有那个列表。

## 核对方式

```sh
node tools/dev/check-parity.mjs
```

它读 `tools/dev/parity.json` 里的清单，检查每项在两边的实现痕迹
（标记字符串）是否存在，缺哪边就报哪边。
